# The Archive

A GitHub Pages-compatible static version of **The Archive**, a mysterious private communication interface for ARG teams and puzzle groups.

## GitHub Pages Setup

1. Open this repository on GitHub.
2. Go to **Settings** → **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/root`.
5. Save.

The site will be available at:

`https://gh0st1nth3len5.github.io/gh0st1nth3c0de-general-repo-for-random-stuff-/`

## Important Note

GitHub Pages only hosts static websites. This version stores data in the browser with `localStorage`. It can simulate invite access, hidden rooms, profiles, searchable messages, lore, transmissions, and sealed clues, but it cannot provide true server-side authentication, a shared database, WebSockets, or real multi-user chat by itself.
